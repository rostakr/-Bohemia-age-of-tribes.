# BOHEMIA: AGE OF TRIBES

**Forge a tribe. Rule the land. Shape Bohemia.**

Historical 3D real-time strategy game set in Bohemia and Moravia, developed incrementally with PlayCanvas Engine 2.x for desktop web browsers.

## Production principles

- Classic RTS readability with grounded historical visual direction.
- Evidence-driven performance work and milestone gates.
- Incremental vertical-slice development before broad content expansion.
- Licensed or project-owned production assets only.
- Expensive specialist implementation is reserved for genuinely difficult architecture, rendering, AI, navigation, simulation, or performance work.
